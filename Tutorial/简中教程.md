## 翻译主流程

### 1. 导入漫画

<img src="./mangaku-screenshot.jpg" alt="漫画库页面" width="45%" />

在漫画库页面操作：

- 点击右下角 **＋** 创建文件夹，进入后添加漫画图片
- 点击 **「从漫画文件夹导入」** 直接导入整个文件夹
  - 若目录下有多章子文件夹，会自动创建合集并导入为子章节
  - 若目录直接包含图片，按单本漫画导入
- 点击 **「从 CBZ/ZIP/PDF 导入」** 可直接导入压缩包
- **图片文件名需与阅读顺序一致**（如 `1.jpg`, `2.jpg`），否则页码会乱

### 2. 配置 API

<img src="./setting-screenshot.jpg" alt="设置页面" width="45%" />

软件需自备 API。如果还没有，先看：[API 获取指南](./API获取指南.md)。

> 提示：目标语言由软件界面语言决定。简体中文/繁体中文界面翻译为中文，英文界面翻译为英文，俄文界面翻译为俄文。

在设置页填写：

1. **API 地址** —— OpenAI 兼容接口填写服务商给出的上级地址即可，例如 `https://api.deepseek.com/v1`、`https://open.bigmodel.cn/api/paas/v4`；软件会自动补全 `/chat/completions`，点击「获取模型列表」时会自动补全 `/models`
2. **API Key** —— 妥善保管，勿泄露
3. **模型名称** —— 须与供应商提供的完全一致，可直接从官网复制或点击「获取模型列表」选择

填写完成即返回漫画库。

### 3. 翻译

<img src="./translator-screenshot.jpg" alt="翻译页面" width="45%" />

1. 在文件夹内点击 **「翻译文件夹」**，源语言可按需选择（支持日/英/韩/法/西/葡/德/意/俄/中文等）
2. 等待翻译完成，或预处理结束后点击 **「开始阅读」** 边翻边看
3. 后台翻译完成后会发送带声音的高优先级通知，点击通知可回到漫画库查看结果

> 软件会自动判断作品是否更接近条漫并切换为「条漫滚动」；如需手动调整，可在文件夹的「阅读设置」中修改。
> 全文速译下页数较多（>50）时，建议分批上传或关闭全文速译并调高 API 超时。

### 4. 阅读与调整

- **拖动气泡** 可调整位置，软件会自动保存
- **双击图片** 进入/退出放大模式；进入放大后可使用 **取消键** 或 **加减号** 微调气泡
- **切换页面**：在漫画库文件夹中点击对应图片文件名即可跳转
- **单页重译**：回到漫画库 → 长按该图片 → 点击「重译」
- **大量重译**：关闭「全文速译」后全部重译，或删除漫画换更强模型
- **补缺文字区域**：右上角编辑按钮 → 加号新建空白气泡 → 拖到文字区域 → 绿勾退出；条漫模式下允许跨页创建气泡
- **全文速译太慢**：关闭「全文速译」即可改用逐页并发翻译
- **气泡太挡画面**：在设置中调整游离气泡透明度
- **游离气泡文字色**：游离气泡会根据背景自适应文字颜色
- **翻译文风不佳**：在设置的翻译文风设定中自定义，可让 AI 忽略奇怪符号
- **自定义字体**：在设置页的「字体设置」中可上传字体文件并开启加粗，普通气泡框与悬浮窗气泡框共用同一套字体

## 悬浮窗翻译

在漫画库页点击 **「悬浮窗翻译」**，按提示授予悬浮窗和屏幕捕获权限，并在启动时选择本次使用的翻译语言。右侧出现悬浮球后：

| 操作 | 效果 |
|------|------|
| 单击悬浮球 | 识别并翻译当前屏幕文本 |
| 双击悬浮球 | 清除所有气泡 |
| 长按悬浮球 | 弹出菜单 |

长按菜单选项：

- **编辑模式**：悬浮层拦截触摸，可拖移气泡、长按删除、点击「新增气泡」后框选区域手动补框。确认后自动补翻新增气泡。
- **划屏翻译**：不自动检测，直接进入编辑模式由用户框选。
- **退出**：关闭悬浮窗。

编辑结果仅限当前会话，再次单击识别或退出后重置。无识别结果时先检查屏幕捕获授权和 API 配置。

## 其它设置

### OCR 设置

在设置页点击「OCR 设置」：

- **开启本地 OCR**：离线模式，使用内置引擎
- **关闭本地 OCR**：在线 API OCR，需填写 API 地址/Key/模型
- API OCR 做多语言翻译时不受日/英文选项限制，只需模型支持该语言
- OCR 超时可调高「OCR API 超时（秒）」范围 30–1200

### 多供应商调度

启用后可让多个供应商按权重分担翻译请求。并发数控制的是总并发上限，系统在限额内分配。

### 自定义请求参数

参数默认作用于主供应商，也可单独指定给附加供应商。同一供应商内参数键不可重复。

### 悬浮窗翻译设置

独立配置悬浮窗专用 API 地址/Key/模型，留空时回退主设置。

- **VL 直翻**：将气泡截图直接交给视觉模型翻译，需多模态模型。可设置 VL 翻译线程数。
- **校对模式**：每次识别后自动进入编辑模式。
- **自动清除气泡**：翻页时自动关闭气泡。

## 小技巧

- **导出漫画**：文件夹内支持导出 CBZ、PDF 或纯图片，默认路径为文档目录下的 `manga-translate`。
- **清除翻译缓存**：直接清除应用缓存即可清空悬浮窗等翻译缓存。
- **关闭译名处理加速**：关闭「全文速译」后可单独关闭「译名处理」，保留已有译名上下文同时减少额外处理。
- **合集内导入子章节**：进入合集后点击「导入子章节」，支持多选勾选或单个导入，同名/空目录自动跳过。
